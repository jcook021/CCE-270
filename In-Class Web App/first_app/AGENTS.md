# Project layout

This is a single-file web app. Keep `index.html`, `spec.md`, `prompts.md`, and this `AGENTS.md` at the project root. GitHub Pages serves the root-level `index.html`.

Save new files in the folder that matches their purpose:

- `00_planning/` for planning notes and sketches.
- `01_data/` for data files.
- `02_validation/` for hand calculations and test cases.
- `03_output/` for screenshots and exported results.

Each numbered folder has a `README.md` describing its contents. Do not put app assets or supporting files at the root unless they are one of the designated root files.

Commit after every prompt
